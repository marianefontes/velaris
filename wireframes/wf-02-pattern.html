Como estruturo uma tela de onboarding para um novo usuário do produto?

Beatrice

Padrão recomendado
Onboarding Pattern
Fonte: PatternsPage → Supporting Patterns
Lógica do padrão
Progressive disclosure que introduz funcionalidades-chave via educação contextual sem interromper o fluxo principal. Reduz sobrecarga cognitiva ao sequenciar descobertas em vez de apresentar tudo de uma vez.
Anatomia do padrão
01
Welcome Step
Contexto de valor, sem formulário
02
Role Setup
Personalização mínima (1–2 perguntas)
03
First Action
Quick win imediato no produto
Contexto de uso
First-run experiences, ativação pós-signup, descoberta de features após grandes atualizações e reveals de capacidades baseadas em papel.
Quando não usar
Re-engajamento de usuários experientes — onboarding para quem já conhece o produto cria atrito desnecessário.
