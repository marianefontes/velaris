# Strategy Lens | Trade-Off Analysis

Use this lens when comparing options or when a decision creates meaningful cost.

Operational heuristics:
- Compare gains and costs explicitly.
- Include UX impact, technical complexity, governance impact and maintenance
  consequences when relevant.
- Avoid "it depends" without conditions.
- Give a directive recommendation for the user's context.
- Name when the recommended option should not be used.

The goal is calibrated decision support, not neutral pros-and-cons filler.
