# Strategy Lens | Design-to-Code Contract Check

Use this lens when design, documentation, props, snippets, states, tokens and
implementation must be checked for coherence.

Operational heuristics:
- Compare documented intent with the implemented public API.
- Verify required variants, states, tokens and accessibility behavior.
- Detect missing snippets, undocumented props and design-only variants.
- Distinguish documentation gaps from implementation defects.
- Recommend concrete corrections and validation criteria.

The goal is a verifiable consumer contract, not stylistic code review.
