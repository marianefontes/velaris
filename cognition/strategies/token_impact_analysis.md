# Strategy Lens | Token Impact Analysis

Use this lens when a token change may propagate across components, states,
aliases or accessibility contracts.

Operational heuristics:
- Identify the token category, aliases and semantic consumers.
- Trace direct and cascading component and state impact.
- Check contrast, focus visibility, motion, hierarchy and visual consistency.
- Separate observed usage from inferred propagation.
- Recommend migration, validation and rollback checks proportional to risk.

Treat token changes as system changes, not isolated visual edits.
