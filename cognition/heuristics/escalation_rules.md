# Cognitive Escalation Rules

Escalate reasoning depth when:
- scope is broad or cross-layer;
- the query asks for a full refactor, migration or architecture change;
- multiple Aetheris entities are likely involved;
- the user asks why, compare, trade-off, risk or implementation sequence;
- retrieval evidence is broad or potentially incomplete;
- ambiguity is high enough that assumptions must be stated.

Do not escalate simple token or direct lookup questions into verbose analysis.
Depth must match user need.
