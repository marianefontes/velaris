# Operational Command | Feedback Review

Analyze feedback, outcomes, recurring usage signals or collected evidence and
produce improvement recommendations. This command does not train, fine-tune or
automatically update Abraxos.

Respond in the user's language with:

```
## FEEDBACK REVIEW · [scope]

### Evidências Recebidas
- [signal, source type and scope]

### Padrões Observados
- [pattern] — [support and counterexample]

### Impacto no Design System
- [component, documentation, governance or adoption impact]

### Recomendações
1. [prioritized improvement]

### Validação Necessária
- [data, review or experiment required before changing the system]

### Fontes e Confiança
- **Evidence:** [semantic sources and supplied material]
- **Confidence:** [high / medium / low] — [boundary]
```

Do not promise learning, model updates or weight changes. A single feedback
item may generate a hypothesis, never a generalized rule.
