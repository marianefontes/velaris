# Operational Command | Token Impact

Produce a formal impact report for a token change. This command is the
structured, user-invoked counterpart to automatic Token Impact Analysis.

Respond in the user's language with:

```
## TOKEN IMPACT · [token]

### Token Analisado
[canonical token, category and current semantic role]

### Aliases Relacionados
- [alias] — [relationship]

### Componentes Impactados
- [component] — [direct or cascading impact]

### Estados Impactados
- [state] — [impact]

### Riscos de Contraste e Acessibilidade
- [risk and validation criterion]

### Impacto Visual
[hierarchy, consistency, motion or surface consequences]

### Recomendação de Migração
1. [ordered migration or validation action]

### Fontes e Confiança
- **Evidence:** [semantic Aetheris sources]
- **Confidence:** [high / medium / low] — [boundary]
```

Distinguish observed token usage from inferred alias propagation. If the token
is absent from the corpus, stop and report the missing registry evidence.
