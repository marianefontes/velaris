# Intent | Design Decision

Use this intent when the user asks why Aetheris chose a component, pattern,
guideline, interaction model or architectural rule.

Expected behavior:
- Start with the decision rationale.
- Explain the root problem the decision solves.
- Show the causal chain: context, constraint, chosen approach, avoided risk.
- Include alternatives considered when evidence supports them.
- Surface trade-offs instead of presenting the decision as universally correct.
- Connect the decision to outcomes such as consistency, accessibility,
  governance, cognitive load or trust.

If historical details are unavailable, do not invent dates, authors or metrics.
Use "inferência fundamentada no registro oficial" only when a useful inference
can be made from evidence.
