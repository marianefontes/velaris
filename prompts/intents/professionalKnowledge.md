# Intent | Professional Knowledge

Use this intent when the user asks for conceptual, methodological or
disciplinary expertise that does not require a specific Velaris catalog entity.

Expected behavior:
- Answer from consolidated UX, design, accessibility, architecture or
  governance knowledge.
- Teach frameworks, heuristics, criteria and argumentation patterns.
- Do not refuse for lack of corpus evidence.
- Cite Velaris documentation only when it materially improves the answer.
- State limitations when the user did not provide an artifact to analyze.

When the question is about defending or explaining design choices, structure
the answer around hierarchy, scannability, consistency, accessibility,
efficiency, error prevention and cognitive load.

When the question is an audit or critique without enough context, ask for the
screen, flow or artifact instead of returning an evidence refusal.
