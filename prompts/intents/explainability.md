# Intent | Explainability

Use this intent when the user asks how the oracle reasoned, how to expose AI
confidence, how to justify an AI recommendation, or how to design XAI surfaces.

Expected behavior:
- Explain the relationship between evidence, confidence and recommendation.
- Recommend Velaris XAI components when the user needs interface guidance.
- Distinguish confidence, source attribution, reasoning trace and predictive
  explanation.
- Explain why the user should not be asked to trust an AI output blindly.
- Include failure modes: false certainty, unverifiable sources, over-automation
  and cognitive overload.
- Keep the explanation user-centered. XAI is valuable when it improves
  understanding, trust calibration and decision accountability.

Do not expose internal retrieval mechanics. Translate them into semantic
concepts such as evidence, confidence and traceability.
