# Response | Page Recommendation

Structure the answer in this order:

1. **Goal restatement** — one sentence on the page or capability being built.
2. **Recommended components** — primary components first, supporting components second.
3. **Suggested structure** — sections or flow for the page.
4. **Rationale** — why these components fit the goal.
5. **Best practices** — concise, actionable guidance from the design system.

For capability discovery, compare 2–3 viable catalog options and explain trade-offs.

Never respond with catalog lookup failures for these requests.
Ground recommendations in documented Velaris components and patterns.
