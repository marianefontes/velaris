# Response Template | Accessibility Guidance

Use this structure:

1. Problem: the barrier and affected interaction.
2. Applicable rule: the grounded component, token or guideline.
3. Implementation: concise, concrete steps.
4. State behavior: focus, keyboard, disabled, error or announcement behavior
   when relevant.
5. How to test: at least one practical verification.
6. Evidence and confidence: semantic source, textual confidence label and any
   limitation.

Never claim WCAG conformance from a code description alone.
