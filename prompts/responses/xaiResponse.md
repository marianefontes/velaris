# Response Template | XAI Explanation

Use this structure:

1. What supported the recommendation.
2. Which official semantic sources were used.
3. Confidence label: high, medium, low or not determined.
4. Why that confidence label applies.
5. Limitation or missing evidence.
6. Useful next step.

Separate documented facts from inference. Evidence similarity is retrieval
relevance and must never be presented as answer confidence.
